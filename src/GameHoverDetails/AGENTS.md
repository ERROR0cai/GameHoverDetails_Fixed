# GameHoverDetails — extension notes

## What this extension does

**GameHoverDetails** is a **Playnite** **GenericPlugin** (`net462`, **WPF**) that shows a **hover popup** anchored to the library tile when the cursor is over an item whose `DataContext` resolves to a **`Game`**. Content is **user-configurable** (width, up to five detail fields).

## Implementation

1. **Lifecycle** — `GameHoverDetailsPlugin` attaches on `OnApplicationStarted` via `UIDispatcher` / `ApplicationIdle`, mirroring Autogrid’s main-window readiness pattern. Detaches on `OnApplicationStopped`.
2. **Hover** — `GameHoverDetailsHoverService` handles **`PreviewMouseMove`**: resolves **`Game`** and anchor synchronously and updates the popup immediately (no trailing debounce for show/switch). A **separate ~70ms trailing debounce** hides the popup after the pointer leaves game tiles (reduces flicker over gaps). **`PreviewKeyDown`** defers a hide until after Playnite handles the key: if the pointer is still on a game tile the tooltip stays; if the hotkey opened another UI (F4/F9) and hit-test is no longer a game, the popup hides. `Application.Deactivated` / minimize still hide as before. With an anchor, placement uses **`PlacementMode.Custom`** and **`CustomPopupPlacementCallback`**: prefer the **end** side of the target (**right** in LTR, **left** in RTL), else the start side (WPF picks the first option that fits on-screen). List view stays start-aligned under the row. Hover **`FlowDirection`** is applied to the inner chrome only — never the `Popup` (RTL on the popup mirrors custom placement onto the tile). **`ClampPopupToVirtualScreen`** only adjusts **vertical** position in that mode so horizontal side choice is preserved. **`PopupAnimation.None`** plus a short **opacity-only** storyboard runs when opening or switching games; **same `Game.Id`** with unchanged field keys skips rebuilding inner content and replays no enter animation (placement/anchor still updates). Hover is suppressed when globally disabled or when Fullscreen mode is on and **Show hover in Fullscreen** is off (`ApplicationInfo.Mode`). Popup chrome comes from **`HoverChromePalette`**: theme-sync fill is a **darker, slightly desaturated `GlyphBrush` mixed toward black**; icons stay accent; custom uses picker hex for fill/border/icon-bg. **Use game background** draws the game’s overview fanart (`BackgroundImage`, `Stretch.UniformToFill`) under a **#000000** tint scaled by **Background opacity** (checkbox on resets to 50%; 100% is solid black); the panel uses the **Layout width** slider (same as Regular) and **sizes to the field list**; fanart is an **ImageBrush** (Stretch.UniformToFill) so it cannot add extra height; missing fanart uses the Regular fill. Opacity below 100% still frosts the library. Labels, values, and icon glyphs always use Playnite **`TextBrush`**. Hover body/label text uses Playnite’s **`FontFamily`** resource (default **Trebuchet MS**; WPF `Popup` does not inherit the main window font). Dividers use **`HoverChromePalette.Separator`** (own color, separate from the panel border). Opacity below 100% frosts a **GDI `CopyFromScreen` of the popup rect only** (never a `VisualBrush`/`RenderTargetBitmap` of MainWindow — that froze the UI for seconds). **`BlurEffect`** is created only when frost is on; shadow is a cheap offset border, not `DropShadowEffect`. Do **not** use **`MainWindow.MouseLeave`** to close the popup: opening a **`Popup`** caused spurious leave events and flicker.
3. **Fragility** — Playnite does not document item `DataContext` shapes; templates may change between versions. Failures are latched and logged once; the service detaches.

## Settings

- UI strings load from **`Localization/{locale}.xaml`** (Playnite language); English is the fallback. RTL languages (e.g. Hebrew) set **inner** hover/settings **`FlowDirection`** from Playnite language / main window and **mirror** placement (prefer left of the tile).
- **Add-ons → Extension settings → Generic → GameHoverDetails**: **Enable hover details** and **Show hover in Fullscreen mode** stay above a non-clickable **Settings** heading and a tab strip with no divider (Fields, Display, Styling, Layout); the live preview stays on the right. **Fields**: ordered list (top = first in hover), **↑ / ↓** and **Remove**, **Add field** (label, no “a”): click opens the unused-field list and a live search box together; type filters the list; stays open for multiple picks. **Background**: **Use game background** (off by default; Regular fill `#FF1C1C1E` at **90%** opacity; overview fanart / `BackgroundImage`, `Stretch.UniformToFill` so aspect ratio is preserved and overflow is cropped—typically the sides; black tint scaled by **Background opacity**; turning the checkbox on always resets opacity to **50%**; height follows the field list like Regular); **Use Playnite theme colors** (off by default); fill picker; opacity; **Show border** (off by default; color nested under the checkbox) and **Show dividers** (on by default; 1px lines between field blocks; color nested under the checkbox, default `#FF444444`, separate from border). Fanart mode hides the background **color** picker. **Layout**: appear delay (0–500 ms, default 30), width (120–500 px, default 188), **field columns** (1–3, default 1; Cover / background / description span the full width), field spacing (default 10), padding around the field/icon list (4–32 DIP, default 12). **Display**: **regular text size** first (9–20, default 14); then **Show titles** with **title text size** nested under it (8–16, default 10); then **Show icons** (on by default) with **icon style** (Huge Icons Stroke Rounded default, Unicons Line, Phosphor), **icon size** (8–40 DIP chip, default 19), **icon padding** (0–16 DIP around the glyph, default 8; chip grows, icon size stays), and **Show icon background** nested under that (off = glyph only; default on; **background style** Soft rounded default, plus Circle / Rectangle / Rounded / Squircle / Arch / Tile / Leaf; icon-background default `#FF121212`). Checkbox-dependent controls stay indented **25 DIP** under their parent so they line up with the checkbox **label** (Playnite Default: 18px mark + borders + 5px gap), not the box; see **`.cursor/rules/gamehoverdetails-settings-nesting.mdc`**. Slider titles and checkboxes use Playnite’s theme `Label` / `CheckBox` styles (same as Autogrid) — do not replace those styles without `BasedOn`. The Fields list stays compact. Editing a swatch/hex or **Reset to default colors** turns theme-sync off. Labels, values, and **icon glyphs always use Playnite `TextBrush`**. Up to **five** detail fields (factory default **Time Played**, **Last Played**, **Library**, **Developer**). The hover popup **dismisses as soon as the pointer moves onto the panel**. Body has no inner scroll; fields fill **1–3 columns** (left to right, then down).

## Gotchas

- Keep **`GameHoverDetails_BA249C5D`**, **`GameHoverDetails.dll`**, and plugin **`Guid`** stable for shipped users.
- **Preview vs hover parity** — `HoverFieldListBuilder.Fill` is the only field-list builder. Live hover passes `HoverFieldListSource.ForLiveGame` (`OmitEmptyArt = true`). Settings preview chrome stays in XAML (`PreviewChromeBorder`, fanart, tint); `PreviewFieldsHost` is a `StackPanel` filled by the same builder (`OmitEmptyArt = false`, sample-text / art-cache fallbacks). Description is **plain text** (HTML stripped) capped at **3 lines**. Multi-column layout (`HoverFieldColumnCount`) is shared; Cover / background / description span full width. Do not add a second XAML `DataTemplate` for field rows.
- **`EndEdit`** only persists JSON — do not re-assign hex/field lists on Save (that unchecks theme-sync and rebuilds the settings preview). Flush hover at **ApplicationIdle** and skip chrome/fanart decode while the popup is closed (Save used to freeze Playnite 1–3s). Settings attach once (`Loaded` + `DataContextChanged`); preview art is cached; fallback library image loads are capped (scan + decode). Settings preview uses a cheap offset shadow, not `DropShadowEffect`. Hover live-updates are suppressed for the settings session and flushed once on Save/Cancel.
- Do not set **`FontWeight`** on **`TabItem`** (selected-tab SemiBold inherits into every checkbox and label in the panel). Bold only the tab **header chrome**; keep tab content `FontWeight` Normal. Slider titles are theme `Label`s (Autogrid-style), not SemiBold. Any CheckBox/Label keyed style must `BasedOn` the Playnite type or it falls back to WPF’s 12px chrome.
- Do not use **`MainWindow.MouseLeave`** to close the hover popup (spurious leave when a `Popup` opens).
- Do not poll hit-testing to close on hotkeys; **`PreviewKeyDown`** hides only after the key is processed **and** the pointer is no longer on a game.
- Hover is off in Fullscreen by default (`HoverDisabledInFullscreen`); Desktop and Fullscreen are separate Playnite processes — toggle **Show hover in Fullscreen mode** from Desktop add-on settings.
- Theme-sync fill is a darkened, slightly desaturated **`GlyphBrush`** mixed further toward black (not `PopupBackgroundBrush`); editing pickers or Reset turns **Use Playnite theme colors** off. Field dividers use **`HoverChromePalette.Separator`** (own hex; theme-sync is a slightly lighter theme border). Labels, values, and icon glyphs always use Playnite **`TextBrush`**. Hover text uses Playnite **`FontFamily`** (set on each body/label block — popup HWNDs do not inherit the app font). Frosted backdrop is live-hover only (settings preview is tint-only). Do not snapshot MainWindow with `VisualBrush`/`RenderTargetBitmap` — capture the popup screen rect only, and only while chrome opacity is still near 0.
